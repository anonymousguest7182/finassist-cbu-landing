# ПРОМПТ ДЛЯ ГЕНЕРАТОРА ЛЕНДИНГА — FinAssist

Создай одностраничный лендинг для финтех-продукта **FinAssist** — AI-powered Personal Finance Manager, разработанный для хакатона Центрального Банка Узбекистана.

## Технические требования
- React + TypeScript + Tailwind CSS
- Полностью адаптивный (mobile-first: 360px → 1440px)
- Плавные scroll-анимации (используй framer-motion или CSS animations)
- Тёмная тема (основной фон — градиент от #0A0F1C до #111827)
- Акцентный цвет: emerald (#10B981), вторичный: (#0D7C3D)
- Шрифт: Inter (Google Fonts)
- Язык контента: Русский
- Иконки: lucide-react
- Без внешних картинок — всё через SVG-иллюстрации, градиенты, glassmorphism-карточки

## АНИМАЦИИ И МИКРО-ВЗАИМОДЕЙСТВИЯ

1. **Scroll-reveal**: все секции появляются с fade-up анимацией при скролле (stagger для карточек — появляются одна за другой)
2. **Hero мокап**: при скролле слегка уходит вверх с параллакс-эффектом
3. **Цифры**: анимированный count-up для чисел (780 для CBU-Score, 3 450 000 для баланса) при попадании в viewport
4. **Табы AI**: контент меняется с crossfade, 300ms
5. **Кнопки CTA**: при hover — glow-эффект (box-shadow с emerald opacity)
6. **Карточки features**: при hover — translateY(-4px) + border-color transition
7. **Навбар**: прозрачный наверху, backdrop-blur при скролле
8. **Gradient text shimmer**: на hero заголовке — бегущий блик по градиентному тексту (бесконечная анимация, subtle)
